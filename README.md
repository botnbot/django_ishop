##  Описание

Проект позволяет:

 Управлять категориями и товарами\
 Загружать данные через фикстуры и кастомные команды\
 Использовать Django Admin

------------------------------------------------------------------------

##  Структура проекта

``` bash

django_ishop/
│
├─ catalog # Django приложение 
├─ config # настройки проекта
├─ static # статические файлы проекта
├─ manage.py# утилита командной строки Django
├── .env_example   # пример заполнения файла .env
├── poetry.lock    # зависимости проекта
├── pyproject.toml # настройки Poetry
├── .gitignore     # Игнорируемые файлы (venv, __pycache__, .env и др.)
├── LICENSE        # Лицензия проекта (MIT)
└── README.md      # Документация проекта
```

------------------------------------------------------------------------

##  Установка и запуск

``` bash
git clone https://github.com/botnbot/django_ishop.git
cd django_ishop
pip install poetry
poetry install
poetry shell
```

------------------------------------------------------------------------

##  Быстрый старт (миграции, статика, сервер)

``` bash
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py runserver
```
| URL                               | Описание              |
|-----------------------------------|-----------------------|
| `http://127.0.0.1:8000/`          | Главная страница      |
| `http://127.0.0.1:8000/admin/`    | Панель администратора |
| `http://127.0.0.1:8000/contacts/` | Контакты              |


------------------------------------------------------------------------

##  Заполнение БД (фикстуры)

``` bash
python manage.py loaddata categories
python manage.py loaddata products
```

Или кастомной командой:

``` bash
python manage.py load_catalog
```

------------------------------------------------------------------------

##  Админ-панель

Создать суперпользователя:

``` bash
python manage.py createsuperuser
```

Открыть:\
`http://127.0.0.1:8000/admin/`

##  Проверка данных (Django shell)
