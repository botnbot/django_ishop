## Описание

Проект включает:

-   Каталог товаров (CRUD, валидация, загрузка изображений)
-   Блог с постами (CRUD, фильтрация, счётчик просмотров)
-   Админ‑панель Django
-   Работа с фикстурами и кастомными management-командами

------------------------------------------------------------------------

## Структура проекта

    django_ishop/
    ├─ catalog/        # Приложение для работы с товарами
    ├─ blogera/        # Приложение для блога
    ├─ config/         # Глобальные настройки Django
    ├─ static/         # Статические файлы
    ├─ media/          # Загружаемые изображения
    ├─ manage.py
    ├─ pyproject.toml
    ├─ poetry.lock
    └─ README.md

## Установка и запуск

``` bash
git clone https://github.com/botnbot/django_ishop.git
cd django_ishop
pip install poetry
poetry install
poetry shell
```

------------------------------------------------------------------------

## Быстрый старт

``` bash
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py runserver
```

Основные URL:

  URL                        Описание
  -------------------------- ------------------
  `http://127.0.0.1:8000/`   Главная
  `/admin/`                  Админ‑панель
  `/products/`               Список продуктов
  `/blogs/`                  Список постов

------------------------------------------------------------------------

## Заполнение БД (фикстуры)

``` bash
python manage.py loaddata categories
python manage.py loaddata products
```

или:

``` bash
python manage.py load_catalog
```

------------------------------------------------------------------------

## Админ-панель

``` bash
python manage.py createsuperuser
```

Открыть:\
`http://127.0.0.1:8000/admin/`

## Валидация форм

###  Запрещённые слова

Поля **name** и **description** проверяются на слова:

    казино, криптовалюта, крипта, биржа,
    дешево, бесплатно, обман, полиция, радар

Реализовано через:

-   `clean_name()`
-   `clean_description()`
-   список запрещённых слов хранится в константе.

###  Валидация цены

Метод `clean_price()` проверяет:

-   цена не может быть отрицательной;
-   выводится корректный `ValidationError`.

## Работа с изображениями

Поддерживается:

-   загрузка нового изображения;
-   сохранение старого при редактировании;
-   удаление изображения выбором галки **«Удалить текущее изображение»**
    (кастомизация `ClearableFileInput`);
