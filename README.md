## 📌 Описание

Проект включает:

-   каталог товаров (CRUD, валидация, изображения);
-   блог с публикациями и счётчиком просмотров;
-   кастомную модель пользователя;
-   регистрацию и отправку приветственных писем;
-   авторизацию и защиту доступа;
-   Django Admin;
-   кеширование через Redis;
-   сервисный слой бизнес-логики.

## ⚙ Установка и запуск

git clone https://github.com/botnbot/django_ishop.git cd django_ishop
pip install poetry poetry install poetry shell

Создай .env:

SECRET_KEY=... DEBUG=True DATABASE_NAME=... DATABASE_USER=...
EMAIL_HOST_USER=YOUR_EMAIL@gmail.com EMAIL_HOST_PASSWORD=APP_PASSWORD

------------------------------------------------------------------------

## 🚀 Быстрый старт

python manage.py migrate python manage.py collectstatic --noinput python
manage.py runserver

## 🔐 Роли и права доступа

Используются Django Groups и Permissions.

### Владельцы

-   редактировать свой продукт
-   удалять свой продукт

### Модераторы

Создаются командой: python manage.py create_groups

Могут: - снимать продукты с публикации - удалять любые продукты

Права: - can_unpublish_product - delete_product
